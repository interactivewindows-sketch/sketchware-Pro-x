Presentación

Un espacio para crear y organizar proyectos Android

Gestión local

El proyecto está pensado para crear, listar y gestionar proyectos de forma local, manteniendo una experiencia visual y accesible.

Editor visual

Incluye una estructura orientada a componentes visuales y no visuales para prototipado, con una organización clara por pantallas y flujos de trabajo.

Interfaz MIUIX

Se trabaja con una estética oscura, moderna y cercana a la identidad visual de MIUIX, con efectos visuales inspirados en interfaces avanzadas.
