# Imágenes y capturas del README

Esta carpeta está preparada para recibir capturas propias de Sketchware Pro X. No contiene imágenes generadas, descargadas ni tomadas de otros proyectos.

Coloca los archivos con estos nombres para completar las secciones visuales del README:

| Archivo | Captura sugerida | Uso en README |
|---|---|---|
| `app-icon.png` | Icono oficial de la aplicación | Encabezado visual |
| `home-screen.png` | Pantalla principal | Vista previa principal |
| `project-editor.png` | Editor de proyectos | Vista previa del editor |
| `miuix-hyperos-interface.png` | Interfaz inspirada en HyperOS/MIUIX | Vista previa visual |
| `project-setup-ai.png` | Generación o configuración de proyectos | Vista previa de configuración |
| `welcome-screen.png` | Pantalla de bienvenida | Otras pantallas |
| `settings-screen.png` | Pantalla de ajustes | Otras pantallas |
| `about-screen.png` | Pantalla de información | Otras pantallas |
| `file-manager.png` | Gestor de archivos | Otras pantallas |
| `project-preview.png` | Vista previa del proyecto | Otras pantallas |

## Recomendaciones

- Usa capturas propias tomadas de una versión identificable de la aplicación.
- Mantén una orientación y proporción coherentes entre capturas.
- Para las capturas de pantalla, se recomienda PNG o WebP optimizado.
- Evita incluir claves, tokens, datos personales o rutas sensibles.
- Si una captura todavía no está disponible, deja el marcador del README sin modificar o añade posteriormente el archivo correspondiente.

El README referencia estas rutas relativas intencionadamente. No añadas URLs externas de imágenes como sustitución.
